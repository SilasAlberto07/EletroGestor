Política de Privacidade

Última atualização: 5 de outubro de 2026.

Esta política explica como o aplicativo EletroGestor (para Windows e Android) trata as informações de quem o utiliza.

1. Dados que o aplicativo guarda

O EletroGestor guarda as informações cadastradas pelo próprio usuário: dados da empresa, clientes, materiais, valores de mão de obra e orçamentos. Esses dados ficam no próprio aparelho (computador ou celular) e, se o usuário ativar a sincronização, também no Google Drive do próprio usuário.

O EletroGestor não possui servidor próprio e não envia esses dados para o desenvolvedor nem para terceiros.

2. Uso dos dados da conta Google

A sincronização com o Google Drive é opcional. Quando o usuário escolhe "Entrar com Google", o aplicativo solicita apenas:

  • E-mail da conta — para mostrar ao usuário com qual conta está conectado;
  • Acesso a arquivos criados pelo próprio aplicativo no Google Drive (permissão drive.file) — para salvar e ler o arquivo "EletroGestor - dados (não apague).db", que contém os dados do usuário.

O aplicativo não lê, não altera e não apaga nenhum outro arquivo do Google Drive. Os dados obtidos das APIs do Google são usados exclusivamente para a sincronização entre os aparelhos do próprio usuário, não são vendidos, não são usados para publicidade e não são compartilhados com terceiros.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

3. Onde fica o login

A autorização do Google fica guardada apenas no aparelho do usuário (no computador, de forma criptografada). O usuário pode desconectar a qualquer momento em Configurações → Sincronização com o Google Drive → Desconectar, ou remover o acesso em myaccount.google.com/permissions.

4. Exclusão dos dados

Para apagar os dados, basta desinstalar o aplicativo do aparelho e, se usou a sincronização, apagar o arquivo "EletroGestor - dados (não apague).db" do seu Google Drive.

5. Contato

Dúvidas sobre esta política podem ser enviadas pela página do projeto.
